## 📌 Tentang Portfolio

Portfolio personal ini dibuat untuk memperkenalkan diri, menampilkan proyek-proyek yang telah dibuat, serta sebagai sarana komunikasi bagi siapa saja yang ingin menghubungi Helmy Arsyad Darmawan.

Portfolio ini terdiri dari tiga halaman utama:
- **Beranda (index.html)** - Halaman utama dengan sapaan personal, hobi, dan formulir kontak
- **Profil Saya (profile.html)** - Halaman profil lengkap dengan riwayat pendidikan, keahlian, visi & misi
- **Portofolio (portofolio.html)** - Halaman menampilkan proyek dan sertifikat yang telah diraih

## 🛠 Teknologi

Portfolio ini dibangun menggunakan teknologi berikut:

| Teknologi | Deskripsi |
|-----------|-----------|
| **HTML5** | Struktur markup semantic |
| **CSS3** | Styling modern dengan Flexbox, Grid, Animations |
| **JavaScript** | Interaktivitas dan manipulasi DOM |
| **Firebase RTDB** | Real-time database untuk pesan |
| **LocalStorage** | Penyimpanan data lokal |
| **Font Awesome** | Icon library |
| **Google Fonts** | Typography (Inter, Playfair Display, Poppins) |

### Keahlian Teknis
- HTML5: 95%
- CSS3: 90%

- Firebase: 80%
- Git: 75%

## 🚀 Cara Menjalankan

1. **Clone atau Download repository ini**
   ```bash
   git clone https://github.com/helmy-arsyad/portfolio.git
   ```

2. **Buka file HTML**
   - Buka `index.html` di browser favorit Anda
   - Atau gunakan live server extension di VS Code

3. **Untuk pengembangan**
   ```bash
   # Install dependencies (jika ada)
   npm install

   # Jalankan development server
   npx serve
   ```
